# Bet do Suricato

Site estático de jogos demonstrativos, com layout desktop e layout mobile/Android responsivo.

## Publicar no GitHub Pages

1. Crie um repositório GitHub chamado `bet-do-suricato`.
2. Envie `index.html`, `README.md` e `.nojekyll` para a raiz.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. O endereço será `https://SEU-USUARIO.github.io/bet-do-suricato/`.

Não há etapa de build: o GitHub Pages serve diretamente o `index.html`.
